Build after the layout is chosen

  • React table: keyboard-accessible sorting, selection, row menu, empty/error/loading states, and the existing upload flow. Keep the white theme and scoped Tailwind styles.
  • Existing data behavior: server-side search and sorting, 25-file pages, email and minimum-size filters, deduplication, owner links, downloads, and deletion. Basic filters show All files, Images, Documents; Advanced mode lists actual extensions.
  • Configuration: preserve the existing Custom Metadata switches for Owner, Modified date, Modified by, and Size. The mocks show all columns.
  • Integration: a React related-list LWC reached through the development card’s View All action. Local fixtures first, then validation in the authorized development org. The native tab is milestone 5.
  • Review gate: verify search/sort across pages, selection reset, failed-page retry, stale responses after navigation, and upload/delete results. Stop for milestone 4 review.

The React upload transport currently caps files at 2 MB. The existing related list uses Salesforce’s native uploader; larger-file parity needs a separate transport decision.
